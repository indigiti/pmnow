# M4 + M5 Implementation

## M4 — Content Hub Alpha

Implemented:

- Private FastAPI content engine (`127.0.0.1:8788` by default)
- Provider registry and common provider contract
- Manual provider
- WordPress REST provider
- Instagram official/manual-only adapter
- YouTube Data API adapter
- X API/limited adapter
- Provider capability discovery
- Provider test/sync endpoints
- Unified normalized content contract
- PHP `PythonClient` service boundary
- File-backed source/content repositories
- Source credentials resolved from environment variable names, not stored as raw secrets
- Manual content import endpoint
- Source sync endpoint
- Auto-publish option into the existing Story contract

### Engine endpoints

```text
GET  /health
GET  /v1/providers
POST /v1/source/test
POST /v1/source/sync
POST /v1/content/normalize
POST /v1/content/analyze
POST /v1/content/duplicate
POST /v1/content/related
```

### PHP orchestration endpoints

```text
GET  /api/admin/engine/health
GET  /api/admin/providers
GET  /api/admin/sources
POST /api/admin/sources
POST /api/admin/sources/{id}/test
POST /api/admin/sources/{id}/sync
GET  /api/admin/content
POST /api/admin/content/import
POST /api/admin/content/{id}/analyze
GET  /api/admin/clusters
```

The `/api/admin/*` namespace is an integration surface in M4/M5. Full RBAC/editorial UI enforcement belongs to M6.

## M5 — Intelligence Beta

Implemented deterministic intelligence baseline plus an optional external-AI adapter boundary:

- English / Devanagari / mixed-language detection
- Rule + keyword category classification
- Editable taxonomy supplied by PHP
- Pune locality/alias matching
- Conservative named-entity extraction
- Extractive summary generation
- Versioned analysis-result persistence
- Exact duplicate detection
- Near-duplicate text similarity
- Related-story scoring using text + category + location signals
- First-class story clusters
- Auto mapping of category/location slugs back to GUID entities
- Optional `AI_HTTP_ENDPOINT` private adapter; disabled by default

No external AI is silently called. The deterministic intelligence pipeline is the default.

## Persistence

M4/M5 remain No-DB first. New canonical collections are:

```text
storage/data/sources/
storage/data/contents/
storage/data/analysis-results/
storage/data/story-clusters/
storage/data/rules/
```

All records retain UUIDv7 IDs and remain compatible with the future database repositories.

## Run

```bash
cp .env.example .env
php tools/seed.php
./run.sh
```

`run.sh` starts FastAPI and the PHP application together by default.

Manual integration test:

```bash
php tools/import-demo.php
```

Source sync:

```bash
php tools/sync-source.php <source-uuid> 10 0
```

Tests:

```bash
PYTHONPATH=. python3 engine/tests/smoke.py
PYTHONPATH=. python3 tests/engine_http_smoke.py
php tests/smoke.php
# requires FastAPI running:
php tests/m4_m5_smoke.php
```
