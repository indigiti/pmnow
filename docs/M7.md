# M7 — Production Hardening & Certification

M7 hardens the M1–M6 No-DB application without changing the public Story/Content contracts or the repository boundary.

## Security boundary

- Central `SecurityKernel` runs before route dispatch.
- State-changing `/api/*` calls require a session CSRF token.
- State-changing browser requests with an `Origin` header must match `APP_URL` host.
- Admin sign-in has a dedicated 5-minute rate-limit bucket; other mutations have per-minute limits.
- Maximum request body size is enforced before routing.
- Browser security headers include CSP, HSTS (production/HTTPS), frame denial, nosniff, referrer policy and permissions policy.
- Session strict mode and cookie-only sessions are enabled; production can force Secure cookies.
- Login regenerates session ID and CSRF secret.

## SSRF protection

`UrlGuard` exists in both PHP and Python. WordPress source URLs are restricted to public HTTP/HTTPS destinations by default. Localhost, private networks, reserved space and link-local/cloud metadata destinations are rejected. Python follows redirects manually and re-validates every redirect destination.

`ALLOW_PRIVATE_SOURCE_URLS=true` is an explicit development escape hatch and should not be enabled in production.

## Encrypted credential vault

Source API secrets can be stored in `storage/secrets/{source_uuid}.vault` using AES-256-GCM with a key derived from `APP_KEY`.

The Newsroom source screen only shows masked suffixes. Plaintext credentials are decrypted only when constructing the private FastAPI provider request. Existing environment-variable credential references remain supported.

Required vault field names for built-in providers:

- Instagram: `access_token`
- YouTube: `api_key`
- X: `bearer_token`

## Soft quota control

M7 records logical provider calls per source/day and compares them with an editable soft limit. States are:

- healthy: <70%
- watch: 70–84%
- quota_low: 85–94%
- throttled: >=95%

A source is prevented from syncing once the configured soft limit is exhausted. These counters are application soft limits, not authoritative vendor quota balances.

## Error Center

Unhandled PHP exceptions, worker failures, source test failures, source sync failures and editorial-action failures can be written to `system-errors`. Sensitive context keys such as token/password/secret/credential are redacted before persistence. Newsroom operators can mark records resolved.

## System Health

`/admin/system` surfaces PHP, filesystem, FastAPI, Redis/runtime and security posture plus source quota usage.

## Media guardrails

PHP only persists local `/media/*` or safe public HTTP/HTTPS media URLs. Python includes media metadata validation for supported types, dimensions, duration and safe URL schemes. A full downloader/transcoder remains a later media-pipeline concern.

## Runtime templates

`deploy/systemd/` contains FastAPI engine, worker and scheduler timer units. `deploy/nginx/` contains a production-oriented front-controller example that denies private application directories.

## Production checks

Run:

```bash
php tools/security-audit.php --strict
php tools/doctor.php
php tools/healthcheck.php
php tests/m7_smoke.php
PYTHONPATH=. python3 tests/m7_engine_smoke.py
```

Production must use `APP_DEBUG=false`, `ADMIN_DEV_BYPASS=false`, HTTPS, a strong unique `APP_KEY`, Secure cookies and private-source URL blocking.
